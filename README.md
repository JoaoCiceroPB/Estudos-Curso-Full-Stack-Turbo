# 📚 Estudos - Curso Full Stack Turbo

Repositório dedicado ao armazenamento de códigos, exercícios práticos e projetos desenvolvidos durante o curso **Full Stack Turbo** (com o Prof. Alisson Suassuna).

---

## 🛠️ Tecnologias e Conceitos Estudados

- **HTML5:** Estruturação semântica de páginas web.
- **CSS3:** Estilização, Flexbox, CSS Grid e design responsivo.
- **Lógica de Programação:** Fundamentos e algoritmos.
- **Git & GitHub:** Controle de versão e gerenciamento de repositórios.

---

## 📂 Estrutura do Repositório

Os arquivos estão organizados por módulos e aulas práticos para acompanhar a evolução do aprendizado ao longo do curso.
